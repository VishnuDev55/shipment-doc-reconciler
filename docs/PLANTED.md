## What this bundle cannot see

- **`miss_inside_tolerance`** -- 600 g on 12,450 kg. The engine's absolute band is 1 kg, chosen because a re-weigh of a container rarely agrees to the gram, so this is reported as agreement. It is the cost of that band, written down rather than discovered by a customer.

Two limits sit outside the bundle's reach and are stated rather than implied. A value that is wrong on every document -- all four papers copying the same bad figure -- has nothing in the paperwork to contradict it, and only the arithmetic checks catch that when the documents disagree with *themselves*. And invention on a photo or scan is undetectable by code: there is no text layer to check a quote against, which is why `planted_invented_value` needs a sidecar to work.

## Reproducing

```bash
python scripts/build_fixtures.py       # regenerates fixtures/planted/
python scripts/evaluate_planted.py     # the table
python scripts/evaluate_planted.py --write    # rewrite this file
python scripts/evaluate_planted.py --check    # fail on a miss or an alarm
```
